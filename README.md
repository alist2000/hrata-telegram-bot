# ربات تلگرامی هوش مصنوعی (Telegram AI Bot)

این یک ربات پیشرفته تلگرامی بر پایه پردازش ابری Cloudflare Workers و پایگاه داده D1 است که از مدل‌های هوش مصنوعی مختلف (Gemini و Grok) پشتیبانی می‌کند.

## ویژگی‌ها
- **مدیریت کاربران:** پنل مدیریت پیشرفته برای بررسی کاربران، مدیران و آمار ربات.
- **سهمیه روزانه:** تعیین محدودیت تعداد سوالات در روز برای کاربران عادی و قابلیت بازنشانی یا تغییر سهمیه هر کاربر.
- **عضویت اجباری:** الزام کاربران به عضویت در کانال مشخص شده.
- **تغییر خودکار هوش مصنوعی:** پشتیبانی از Gemini-3.8-Flash با تایم‌اوت هوشمند و Fallback به Grok در صورت شلوغی سرور.
- **زبان فارسی:** تمامی متن‌ها و ساختار پیش‌فرض ربات برای تعامل به زبان فارسی بهینه‌سازی شده است.

---

## ۱. راهنمای دیپلوی (استقرار)
برای اعمال هرگونه تغییرات جدید در کد، باید ربات را مجددا روی Cloudflare مستقر کنید. برای این کار:

۱. ابتدا خط فرمان (Command Prompt یا PowerShell) را در پوشه پروژه باز کنید.
۲. دستور زیر را وارد کنید:
```bash
npx wrangler deploy
```
*نکته: در ویندوز ممکن است نیاز باشد دستور را به صورت `cmd /c "npx wrangler deploy"` اجرا کنید.*

---

## ۲. راهنمای دیباگ (خطایابی)
اگر ربات خطایی داد یا کار نکرد، می‌توانید به صورت زنده لاگ‌های سرور را مشاهده کنید:

۱. در خط فرمان دستور زیر را وارد کنید:
```bash
npx wrangler tail
```
۲. به ربات تلگرامی پیام دهید و همزمان لاگ‌های ایجاد شده در صفحه خط فرمان را بررسی کنید.

## ۳. تغییر تنظیمات ربات و هوش مصنوعی

### آپدیت کردن API Key جمنای (Gemini)
اگر می‌خواهید توکن جمنای را آپدیت یا تغییر دهید، دستور زیر را در پوشه پروژه اجرا کنید:
```bash
npx wrangler secret put GEMINI_API_KEY
```
سپس کلید API جدید خود را Paste کرده و Enter بزنید. *(نکته: تغییر Secretها به صورت خودکار نسخه جدیدی از ربات را در سرور کلودفلر دیپلوی می‌کند، پس نیازی به دیپلوی مجدد نیست)*

### آپدیت کردن توکن تلگرام
به همین ترتیب برای آپدیت کردن توکن ربات تلگرام:
```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
```

### تغییر مدل به Grok (xAI)
کد ربات طوری نوشته شده که اگر کلید `GROK_API_KEY` در تنظیمات (Secrets) وجود داشته باشد، اولویت با Grok خواهد بود.
برای فعال‌سازی Grok:
```bash
npx wrangler secret put GROK_API_KEY
```
برای بازگشت به Gemini، می‌توانید کلید Grok را حذف کنید:
```bash
npx wrangler secret delete GROK_API_KEY
```

### تغییر زبان یا رفتار پیش‌فرض هوش مصنوعی
در فایل `src/index.js` متغیری به نام `SYSTEM_PROMPT` در بالای فایل وجود دارد. اگر می‌خواهید رفتار، زبان یا لحن ربات را تغییر دهید، کافی است متن داخل `SYSTEM_PROMPT` را ویرایش کرده و مجدداً دیپلوی کنید (`npx wrangler deploy`).

### تغییر کانال اجباری یا محدودیت روزانه
از طریق تنظیم Secrets می‌توانید این مقادیر را تغییر دهید. مثال:
```bash
npx wrangler secret put DAILY_QUESTION_LIMIT
npx wrangler secret put REQUIRED_CHANNEL
```

## ۴. راهنمای پنل مدیریت
مدیران تعیین شده (در حال حاضر `@ali_safari_t` و `@hrata`) به قابلیت‌های زیر دسترسی دارند:

هنگامی که مدیران دستور `/start` را می‌زنند، دو گزینه می‌بینند:
- **ورود به پنل مدیریت:** برای مدیریت ربات.
- **ورود به عنوان کاربر عادی:** برای تست کردن ربات از دید یک کاربر معمولی.

مدیران می‌توانند از دستورات زیر مستقیماً استفاده کنند:
- `/admin` : باز کردن پنل شیشه‌ای مدیریت
- `/reset <user_id>` : بازنشانی سهمیه استفاده امروز یک کاربر
- `/setlimit <user_id> <تعداد>` : تغییر ظرفیت سوالات روزانه یک شخص خاص
- `/addmanager @username` : افزودن یک شخص جدید به عنوان مدیر
- `/removemanager @username` : حذف مدیر
- `/block <user_id>` : مسدود کردن فرد مزاحم
- `/unblock <user_id>` : خارج کردن از لیست مسدودها
- `/stats` : دیدن آمار کلی استفاده کاربران
- `/users` : لیست آخرین کاربرانی که از ربات استفاده کرده‌اند
- `/managers` : لیست مدیران ربات
