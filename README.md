## 🔍 چرا پیام پاسخ داده نشد و چگونه برطرف شد؟

علت مشکل قبلی **Read timeout expired** در تلگرام بود:
- وقتی کاربر سوالی از ربات می‌پرسید، تلگرام حداکثر چند ثانیه منتظر دریافت پاسخ HTTP می‌ماند. اگر پاسخ مدل کمی طول می‌کشید، تلگرام ارتباط وب‌هوک را قطع می‌کرد و پیامی به کاربر نمی‌رسید.
- **راه حل اعمال شده:** کد با `ctx.waitUntil` بازنویسی شد؛ اکنون کلودفلر بلافاصله کد تاییدیه (200 OK) را به تلگرام برمی‌گرداند و پاسخ هوش مصنوعی را در پس‌زمینه بدون قطعی تا انتها پردازش و ارسال می‌کند.

## 🛠 نحوه دیباگ و مشاهده لاگ‌های زنده

برای اینکه متوجه شوید ربات در لحظه چه کاری انجام می‌دهد و آیا خطایی وجود دارد یا خیر، ۲ ابزار قدرتمند در اختیار دارید:

### روش ۱: مشاهده لاگ‌های زنده در ترمینال (Wrangler Tail)
در پوشه پروژه دستور زیر را بزنید:
```powershell
npx wrangler tail
```
حالا در تلگرام به ربات پیام دهید. تمام درخواست‌ها، ارورها و لاگ‌ها به صورت زنده در ترمینال شما چاپ می‌شوند.

### روش ۲: بررسی وضعیت وب‌هوک تلگرام
در مرورگر یا ترمینال آدرس زیر را فراخوانی کنید:
```
https://api.telegram.org/bot<TOKEN>/getWebhookInfo
```
اگر خطایی در ارسال پیام از سمت تلگرام به کلودفلر باشد، در فیلد `last_error_message` نشان داده می‌شود.

## 📂 ساختار فایل‌ها و محل اعمال تغییرات

| نام فایل | نقش و کاربرد |
|---|---|
| `src/index.js` | **هسته اصلی ربات** (دریافت پیام، منطق عضویت کانال، تماس با Gemini/Grok، ذخیره دیتابیس) |

| `.env.example` | راهنمای متغیرهای محیطی |

## 🧠 تغییر پرامپت و رفتار هوش مصنوعی

برای تغییر نحوه صحبت، لحن یا دستورالعمل هوش مصنوعی، فایل `src/index.js` را باز کنید و بخش زیر را ویرایش نمایید:

```javascript
const SYSTEM_PROMPT = `شما یک دستیار هوش مصنوعی مودب، مفید و دقیق در تلگرام هستید.
قوانین:
- پاسخ‌ها را به زبان فارسی روان، کوتاه و دقیق ارائه بده. حداکثر ۲ تا ۳ بند.
- از به کار بردن علامت‌های گیومه غیرضروری و خط فاصله طولانی خودداری کن.
- پاسخ محتوای نامناسب یا خطرناک را نده.
`;
```

## 🔄 سوییچ بین Gemini و Grok

کد به صورتی طراحی شده که به شکل خودکار سرویس‌ها را مدیریت کند:

### استفاده از Gemini (پیش‌فرض):
به صورت خودکار از مدل سریع `gemini-3.8-flash` استفاده می‌کند.

### سوییچ به Grok (xAI):
کافی است در ترمینال کلید API گروک را وارد کنید:
```powershell
npx wrangler secret put GROK_API_KEY
```
*(ربات خودکار متوجه می‌شود و پرسش‌ها را از Grok می‌پرسد).*

### برگشت مجدد به Gemini:
برای حذف کلید Grok و بازگشت به Gemini:
```powershell
npx wrangler secret delete GROK_API_KEY
```

## ⚙️ تغییر محدودیت تعداد سوال و کانال اجباری

برای تغییر این مقادیر بدون دست زدن به کد:

- **تغییر سهمیه روزانه (مثلا به ۱۰ سوال):**
```powershell
npx wrangler secret put DAILY_QUESTION_LIMIT
# عدد 10 را تایپ کنید
```

- **تغییر کانال تلگرام:**
```powershell
npx wrangler secret put REQUIRED_CHANNEL
# نام کاربری جدید کانال را بدون @ وارد کنید
```

## 📊 مشاهده و مدیریت اطلاعات دیتابیس D1

تمام کاربران، پرسش‌ها و پاسخ‌ها در دیتابیس D1 کلودفلر ذخیره می‌شوند.

- **مشاهده تعداد کاربران ثبت‌نام شده:**
```powershell
npx wrangler d1 execute hrata-bot-db --remote --command="SELECT user_id, first_name, username FROM users;"
```

- **مشاهده آخرین سوالات پرسیده شده:**
```powershell
npx wrangler d1 execute hrata-bot-db --remote --command="SELECT user_id, question, answer, asked_at FROM questions ORDER BY asked_at DESC LIMIT 5;"
```
